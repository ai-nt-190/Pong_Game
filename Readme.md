# 🏓 Pong Game

A simple recreation of the classic Pong game, built using Python and the Turtle module.

Remember the old arcade game where two players control paddles and try to keep a ball from getting past them? That's exactly what this project is about!

## 🎮 About the Game

This is a basic two-player Pong game where each player controls a paddle and tries to hit the ball back to their opponent.

The goal is simple: keep the ball in play, score points, and try to beat the other player.

I built this project to practice Python and get a better understanding of how to create simple games using the Turtle module.

## ✨ Features

- Classic two-player Pong gameplay.
- Keyboard controls for both paddles.
- Ball movement and bouncing.
- Collision detection with paddles and walls.
- Score tracking for both players.
- Simple retro-style game interface.

## 🛠️ Built With

- **Python** – Game logic and functionality.
- **Turtle** – Graphics and game interface.
